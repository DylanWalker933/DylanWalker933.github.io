# 个人博客

基于 [quietseek/home](https://github.com/quietseek/home) 模板搭建的个人主页，托管在 GitHub Pages。

在线访问：<https://dylanwalker933.github.io/>

## 自定义

编辑 `index.html` 中的 `site`、`profile`、`socialLinks`、`about` 等数据对象，即可修改站点名称、头像、简介、社交链接等内容。

## 本地预览

```bash
python -m http.server 3000
```

然后打开 <http://localhost:3000>。
